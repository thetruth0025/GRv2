# GRv2

A collection of small, self-contained web apps.

| App | What it does |
| --- | --- |
| [`bom-analyzer/`](bom-analyzer/) | Upload one or more bills of materials and compare DigiKey, Mouser and TrustedParts on price, lead time, stock availability and lifecycle status, side by side. Produces a printable summary report and a styled Excel workbook. Web app plus a CLI, on a dependency-free Python backend. |
| [`shipping-calculator/`](shipping-calculator/) | Calculate pallet count, weight and dimensions for IT equipment shipments against pouch and despatch limits. |
| `index.html` | Gaming Identified — photograph, identify and list video games for sale. |
