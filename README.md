# GRv2

A collection of small, self-contained web apps.

| App | What it does |
| --- | --- |
| [`bom-analyzer/`](bom-analyzer/) | Upload a bill of materials and compare DigiKey and Mouser on price, lead time, stock availability and lifecycle status, side by side. Python backend plus a static frontend. |
| [`shipping-calculator/`](shipping-calculator/) | Calculate pallet count, weight and dimensions for IT equipment shipments against pouch and despatch limits. |
| `index.html` | Gaming Identified — photograph, identify and list video games for sale. |
