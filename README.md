# GRv2

A collection of small, self-contained web apps.

| App | What it does |
| --- | --- |
| [`bom-analyzer/`](bom-analyzer/) | Search part numbers, or upload one or more bills of materials, and compare DigiKey, Mouser and TrustedParts on price, lead time, stock availability and lifecycle status, side by side. Produces a printable summary report, a styled Excel workbook, and a per-program DMSMS case form for parts whose supply is ending, with alternatives from Nexar. Web app plus a CLI, on a dependency-free Python backend. |
| [`shipping-calculator/`](shipping-calculator/) | Calculate pallet count, weight and dimensions for IT equipment shipments against pouch and despatch limits. |
| `index.html` | Gaming Identified — photograph, identify and list video games for sale. |
