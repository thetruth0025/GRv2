# Sample files

Drop a real (or dummy) `.vsdx` here so the tool can be tested and fixed against
the actual file structure.

**How to add one from GitHub:**

1. Open this folder on the branch:
   `https://github.com/thetruth0025/GRv2/tree/claude/visio-text-replace-pdf-3fpldd/samples`
2. Click **Add file → Upload files**.
3. Drag your `.vsdx` into the page.
4. Make sure the branch at the bottom is `claude/visio-text-replace-pdf-3fpldd`,
   then **Commit changes**.

Helpful to include in your message after uploading:

- The **file name** you added.
- The **exact text** you typed into *Find* (copy/paste it).
- Whether the drawing shows a **"Sheet X of Y"** block and a **REV** block.

A dummy file made from the same Visio template (with fake text) is perfectly
fine — it's the internal structure that matters, not the content.
