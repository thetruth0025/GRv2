! Backend not reachable

This app needs its Python backend running. Neither supplier API can be called straight from a browser: DigiKey requires an OAuth client secret and Mouser requires an API key, and neither sends the CORS headers a browser would need.

  1. Get free API credentials: a client ID and secret from developer.digikey.com, an API key from mouser.com/api-hub, and one from trustedparts.com under My Account → Additional Features. Any one alone is enough to start.
  2. In bom-analyzer/, copy .env.example to .env and fill in the credentials you have.
  3. Run python3 server.py — or py server.py on Windows (Python 3.8 or newer, standard library only, nothing to install).
  4. Open http://localhost:8787, or set the backend URL in Settings if you are running it elsewhere.

Pricing, stock and lifecycle data comes live from the DigiKey, Mouser and TrustedParts APIs. TrustedParts aggregates authorized distributors — expand a row to see every distributor it found. Always confirm on the supplier's own page before placing an order — stock moves fast.
